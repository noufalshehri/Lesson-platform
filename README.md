# منصّة مضبوط للدروس — Lesson Platform

منصّة عربية (RTL) للمعلمات في السعودية — رياض الأطفال والابتدائي:

- **استوديو قوالب**: المعلمة تعبّي المحتوى ويطلع العرض جاهز (7 تصاميم، 10 أنواع شرائح، عرض ثلاثي الأبعاد).
- **دروس جاهزة** مرتبطة بالمناهج السعودية + **وضع رحلة الدرس** التفاعلي.
- **18 لعبة تعليمية** (منها تركيب القطع، البحث عن الكنز، ذاكرة المطابقة) + **نظام تحفيز** (نجوم، شارات، شخصيات أصلية: رحّال، سالم، وردة، فهد، لمعة).
- **فصلي (إدارة صفية كاملة)**: حضور وغياب، اختيار عشوائي من الحاضرين، نقاط بأسبابها، ملف لكل طالب، جدول درجات، استيراد الأسماء من Excel/CSV، تقارير Excel وPDF، ونسخة احتياطية.
- **التواصل مع أولياء الأمور**: تقرير كامل لكل طالبة (الحضور وأيام الغياب، النقاط بأسبابها، الشارات، الدرجات، نقاط القوة وما يحتاج متابعة، كلمة المعلمة، وتوقيع ولي الأمر) للطباعة أو PDF، وملخص جاهز عبر واتساب، وسجل تواصل.
- **خدمات الاختبارات**: بناء ورقة اختبار (اختيار من متعدد، صح وخطأ، أكمل، مقالي) بترويسة المدرسة، نموذج (ب) بترتيب مختلف، نموذج الإجابة، تحليل النتائج (المتوسط، الإتقان، التوزيع، خطة علاجية وإثراء)، بطاقات أرقام الجلوس، ومؤقت الاختبار على الشاشة.
- **قياس الأثر**: مقارنة قبلي/بعدي مع متوسط التحسن وحجم الأثر والكسب المعياري ونسبة الإتقان، وأثر الاستراتيجية على الحضور والنقاط، وتقرير مطبوع.
- **لوحة إنجاز الفرق**: لوحة فلّين تُعلّق فيها شهادات الإنجاز لكل فريق طوال الترم، مع عرض ملء الشاشة وأرشفة الترم.
- **صانع رمز QR**: رابط، نص، واتساب، بريد، واي فاي، مع ألوان ونص تحت الرمز وتنزيل PNG وطباعة عدة نسخ.
- **لوحة المعلمة** (دروسي، ألعابي، فصولي، اشتراكي) و**لوحة الإدارة** (المحتوى، المعلمات، الباقات، الملفات).
- **باقات**: مجانية / أساسية / احترافية.

## البنية

```
public/                 الواجهة (HTML/CSS/JS بدون build)
functions/api/[[path]].js   الـ API على Cloudflare Pages Functions
schema.sql              جداول قاعدة البيانات D1
wrangler.toml           إعدادات Cloudflare
```

الواجهة تكتشف وضعها تلقائياً:
- على Cloudflare → حسابات حقيقية (بريد + كلمة مرور) وقاعدة بيانات D1.
- لو فتحتِ `public/index.html` مباشرة → وضع محلي يحفظ في المتصفح فقط (للتجربة).

## النشر على Cloudflare (مرة وحدة)

1. **Workers & Pages → Create → Pages → Connect to Git** واختاري هذا المستودع.
   - Framework preset: **None**
   - Build command: *(فاضي)*
   - Build output directory: **`public`**
2. **D1 → Create database** باسم `madbot-lessons`، ثم من تبويب **Console** الصقي محتوى `schema.sql` وشغّليه.
3. في مشروع Pages → **Settings → Bindings → Add → D1 database**:
   - Variable name: **`DB`** ← اختاري `madbot-lessons`.
4. **Settings → Variables and Secrets**:
   - `ADMIN_EMAILS` = بريدك (أو أكثر من بريد مفصولة بفاصلة) — صاحبة هذا البريد تشوف لوحة الإدارة.
   - `DEMO_PAYMENTS` = `true` للتجربة فقط (الدفع وهمي ولا يُخصم شيء). خليه `false` في الإطلاق الفعلي.
5. *(اختياري)* لرفع الصور من لوحة الإدارة: **R2 → Create bucket** ثم Binding باسم **`FILES`**.
6. **Retry deployment**، وبعدها **Custom domains** لربط دومين مثل `app.madbot.store`.
7. سجّلي حساب بنفس البريد اللي حطيتيه في `ADMIN_EMAILS` — تصيرين المديرة.

### تشغيل محلي (اختياري)

```bash
npx wrangler d1 execute madbot-lessons --local --file=schema.sql
npx wrangler pages dev
```

## الأمان

- كلمات المرور مشفّرة بـ PBKDF2 (100,000 دورة) + ملح لكل مستخدم.
- الجلسة كوكي `HttpOnly; Secure; SameSite=Lax`، والتوكن محفوظ مُجزّأ (hash) في القاعدة.
- كل معلمة تقرأ وتكتب بياناتها فقط؛ حقول الاشتراك (الباقة، التاريخ، المدفوعات) لا تتغير إلا من الخادم أو المديرة.
- حد لمحاولات الدخول (8 محاولات كل 15 دقيقة).

## قبل الإطلاق الفعلي — مهم

- **الدفع الحالي تجريبي.** لازم ربط بوابة دفع حقيقية (مثل Moyasar أو Tap أو دفع سلة) مع webhook يحدّث الباقة في `teachers/<uid>`.
- **قفل المحتوى حسب الباقة يتم في الواجهة**؛ لو المحتوى المدفوع حساس، ينقل التحقق للخادم.
- **محتوى الدروس الجاهزة** يحتاج مراجعة تربوية ومطابقة لآخر طبعة من المناهج.
- الشخصيات والرسومات أصلية؛ لا تضيفي شخصيات محمية بحقوق (ماريو، إلسا…).
- مكتبة تصدير PowerPoint تُحمّل من cdnjs وقت الاستخدام.
